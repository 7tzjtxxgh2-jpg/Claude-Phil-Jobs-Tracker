# Remediation Plan — PhilJobs Tracker

**Companion to `AUDIT-2026-08-21.md`.** Every one of the 27 findings is assigned to a batch
below; nothing from the audit is dropped. Written to be followed without me — each batch has a
prompt you can paste into Claude Code on your own machine.

**Total cash cost of the entire plan: ~$32**, of which $29 is the optional backfill.
Everything else comes to about $2.50.

---

## The one thing to understand first

There are two different kinds of "cost" in this project, and almost everything below is the
free kind.

| | What it is | Cost |
|---|---|---|
| **Editing code** | Claude Code on your own machine changing files | **Free** — included in Pro |
| **The scraper calling the API** | Your `CLAUDE` GitHub secret, classifying job ads | Real money, per ad |

Only three activities ever spend money: reclassifying jobs after a prompt change, re-running
the Opus QC, and the backfill. They are marked 💵 below. Everything marked 🆓 costs nothing.

**Do the batches in order.** Batches 1 and 3 are free and make everything after them cheaper —
running them first cuts the paid work from ~$110 to ~$32.

> **Note:** a Claude Code *web/remote* session bills your account. A *local* Claude Code session
> on Pro does not. Run these batches locally.

## Batch 7 — The inference layer
**January 2027 onward · 🆓 · a real project, not an afternoon**

The audit's deepest finding: there is no inference layer at all. Raw counts go straight to the
charts — no seasonal adjustment, no confidence intervals, no "insufficient data" state. This is
what turns the backfill into answers.

```
Read AUDIT-2026-08-21.md Part 6 and Part 9.

I now have multi-year data. Build the analysis layer that doesn't exist yet:
- separate seasonal effect from trend (primary Jul-Dec vs secondary Jan-Jun cycles)
- confidence intervals on every plotted point
- an explicit "insufficient data" state instead of drawing a line through 0-2 jobs
- a proper significance test for "is this category actually growing or declining"

Start by proposing the approach and showing me one worked example for Ethics
before building the whole thing.
```

**Covers:** audit Part 6 methodology findings and the Part 9 rebuild table.
**Only start this after Batch 6** — the analysis needs the history to be worth building.
